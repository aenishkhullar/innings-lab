# 🏏 InningsLab

InningsLab is a cricket performance tracking platform designed for players to record, analyze, and improve their game. It helps batsmen and bowlers track their stats, evaluate performance, and gain insights through a clean and modern interface.

---

## 🚀 Features

- 📊 Track match performance (Runs, Balls, Wickets, etc.)
- 🧠 Smart performance insights
- 👤 User roles (Batsman / Bowler)
- 📈 Stats dashboard
- 🎯 Clean and intuitive UI
- 💾 Data storage and retrieval
